# Asaí Bar — Website Demo

Uma demonstração de site institucional para o **Asaí Bar**, uma lanchonete localizada na Asa Norte, em Brasília, com foco em smoothie bowls, açaí, frutas e paninis.

## Demonstração

**Acesse o site:**
https://asai-bar-showcase.arthurfilo12.workers.dev/

## Sobre o projeto

Este projeto apresenta uma proposta de presença digital para o Asaí Bar, com uma experiência moderna, leve e acolhedora voltada para clientes locais.

A página reúne as principais informações do estabelecimento em uma única interface, facilitando a visualização do cardápio, localização, horário de funcionamento e formas de contato.

## Funcionalidades

* Página única com navegação suave
* Design responsivo para celulares, tablets e computadores
* Seção de apresentação do estabelecimento
* Informações sobre a proposta do negócio
* Cardápio com opções de demonstração
* Galeria de imagens
* Seção de diferenciais
* Área preparada para avaliações de clientes
* Horário de funcionamento
* Localização
* Informações de contato
* Integração com Instagram
* Botões de chamada para ação

## Responsividade

O projeto foi desenvolvido com uma abordagem mobile-first, proporcionando uma experiência adaptada para diferentes tamanhos de tela.

A interface se adapta para:

* Smartphones
* Tablets
* Desktops

## Identidade visual

A identidade visual foi desenvolvida para transmitir uma atmosfera fresca, descontraída e contemporânea, alinhada à proposta de um estabelecimento de bowls, frutas e lanches rápidos.

O layout prioriza:

* Destaque para os produtos
* Apresentação visual dos alimentos
* Navegação simples
* Informações objetivas
* Acesso rápido à localização e contato
* Experiência agradável para clientes locais

## Localização

O conceito apresentado considera o estabelecimento localizado na:

**CLN 202, Asa Norte, Brasília - DF**

As informações de endereço devem ser confirmadas pelo estabelecimento antes de uma publicação oficial.

O projeto funciona como uma **demonstração de conceito de presença digital** para o Asaí Bar, mostrando como o estabelecimento poderia apresentar sua marca, produtos, localização e informações de contato por meio de um site próprio.
