# Asai Bar Showcase

Crie um site profissional, moderno e visualmente marcante de uma página para o estabelecimento local “Asai Bar”, localizado na CLN 202, Asa Norte, Brasília, DF.

CONTEXTO DO NEGÓCIO

O estabelecimento foi identificado como um negócio local de alimentação/lanchonete. Não foram encontradas, nas fontes públicas consultadas, informações suficientemente confiáveis para confirmar cardápio, telefone, horário de funcionamento, redes sociais ou uma descrição oficial da marca.

Portanto:

NÃO invente telefone, Instagram, endereço complementar, horário, preços ou outras informações como se fossem fatos.

NÃO invente avaliações ou depoimentos que pareçam ser de clientes reais.

NÃO invente prêmios, história da empresa, número de anos de funcionamento ou outras credenciais.

Quando uma informação real não estiver disponível, use conteúdo demonstrativo claramente identificável ou deixe um campo preparado para posterior preenchimento pelo proprietário.

O endereço conhecido deve ser apresentado como CLN 202, Asa Norte, Brasília - DF, sem inventar número de loja ou bloco.

OBJETIVO

O site será inicialmente apresentado como uma demonstração visual para o proprietário do estabelecimento. Ele deve parecer um site comercial real e profissional, mas deve deixar claro de forma discreta que determinadas informações são demonstrativas e precisam ser confirmadas pelo proprietário.

A prioridade é fazer o proprietário olhar para a página e pensar:

“Esse poderia ser o site oficial do meu negócio.”

DIREÇÃO VISUAL

Crie uma identidade visual própria para o Asai Bar, evitando completamente aparência de template genérico.

O nome “Asai Bar” deve ser o elemento principal da identidade.

Use uma estética contemporânea de alimentação urbana de Brasília, combinando:

visual jovem;

sensação de comida fresca e apetitosa;

atmosfera descontraída;

elementos visuais inspirados em frutas tropicais e alimentação casual;

tipografia moderna e altamente legível;

bastante contraste;

cards e componentes com acabamento premium;

microinterações discretas;

excelente uso de espaços em branco.

A paleta deve ser escolhida pelo próprio design com base nesse conceito, mantendo boa acessibilidade e contraste.

Evite excesso de elementos, aparência infantil ou um template excessivamente colorido.

HERO

Criar um hero forte com:

ASAI BAR

e uma frase de valor curta e memorável relacionada a alimentação casual, frescor e praticidade.

Não afirmar produtos específicos que não tenham sido confirmados.

Adicionar CTA principal:

Conheça o cardápio

e CTA secundário:

Como chegar

O hero deve ter uma imagem visualmente atraente relacionada ao conceito de alimentação, mas, se uma fotografia real do estabelecimento não estiver disponível, usar uma imagem de demonstração apropriada e não apresentá-la como uma fotografia real do Asai Bar.

SOBRE

Criar uma seção curta apresentando o conceito do negócio de forma genérica e comercial.

Não inventar uma história específica da empresa.

Pode utilizar uma mensagem como conceito de demonstração, deixando claro no código/comentários que o texto deverá ser substituído por informações fornecidas pelo proprietário.

CARDÁPIO / PRODUTOS

Criar uma seção visual de cardápio com aproximadamente 5 itens de demonstração.

Como o cardápio real não foi encontrado, NÃO apresentar esses itens como produtos confirmados do Asai Bar.

Identificar discretamente a seção como:

Sugestões de cardápio — demonstração

ou utilizar placeholders elegantes preparados para substituição.

Cada item deve possuir:

nome;

descrição curta;

espaço para preço;

imagem de demonstração.

O layout deve permitir que posteriormente seja muito fácil substituir os produtos, descrições e preços reais.

GALERIA

Criar uma galeria moderna com 4–6 imagens de demonstração relacionadas ao conceito de uma lanchonete/bar de alimentação.

Não afirmar que as imagens são fotos reais do estabelecimento.

Preparar a estrutura para que o proprietário possa substituir as imagens posteriormente.

DIFERENCIAIS

Criar uma seção com 3 ou 4 benefícios genéricos, sem fazer alegações factuais não verificadas.

Exemplos de conceitos:

praticidade;

atendimento local;

opções para diferentes momentos do dia;

experiência casual.

Escrever os textos de forma natural, sem parecer propaganda corporativa.

DEPOIMENTOS

Criar a estrutura visual para depoimentos, mas NÃO inventar avaliações reais.

Em vez disso, usar placeholders claramente identificados como:

“Depoimento de cliente — substituir por avaliação real”

ou deixar três espaços preparados para avaliações reais que o proprietário poderá inserir posteriormente.

HORÁRIO

Criar uma seção de horário de funcionamento com o título:

Horário de funcionamento

Mas como o horário real não foi confirmado, mostrar:

Horários — confirmar com o estabelecimento

Deixar a estrutura preparada para preenchimento posterior.

LOCALIZAÇÃO

Criar uma seção de localização com:

CLN 202, Asa Norte, Brasília - DF

Adicionar um botão:

Ver localização

Preparar um espaço para mapa.

Não inventar bloco, loja ou número.

CONTATO

Criar uma seção final forte com CTA:

Quer conhecer o Asai Bar?

Adicionar espaços preparados para:

telefone;

WhatsApp;

Instagram;

endereço.

Como esses dados não foram confirmados, usar placeholders claramente identificados no código e na interface de demonstração.

Não criar números ou links falsos.

RODAPÉ

Criar rodapé minimalista contendo:

Asai Bar

CLN 202 · Asa Norte · Brasília - DF

e links para as seções da página.

RESPONSIVIDADE

O site deve ser:

mobile-first;

totalmente responsivo;

excelente em celulares;

excelente em tablets;

excelente em desktop;

rápido;

acessível;

com navegação suave;

sem dependências desnecessárias.

EXPERIÊNCIA

Adicionar:

scroll suave;

animações sutis;

hover states;

botões bem destacados;

navegação fixa ou sticky no desktop/mobile quando fizer sentido;

excelente hierarquia visual;

carregamento otimizado;

SEO básico;

meta title e description;

favicon simples baseado na identidade do Asai Bar.

IMPORTANTE — DEMONSTRAÇÃO

Adicionar uma pequena identificação discreta de que este é um conceito/demonstração e que informações comerciais precisam ser confirmadas pelo estabelecimento.

Não colocar uma marca d'água gigante que prejudique a experiência visual.

O resultado final deve parecer um possível site oficial de alta qualidade, e não uma página genérica criada automaticamente.

Priorize conversão, aparência profissional e facilidade de posterior edição pelo proprietário.

Antes de finalizar, revise todo o conteúdo para garantir que nenhuma informação inventada esteja sendo apresentada como fato.
